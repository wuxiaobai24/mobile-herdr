# Mobile Herdr 0.2.2-beta.12（候选发布说明）

相较已公开的 beta.8，本版增加聊天图片和文件附件、技能选择、对话与终端历史、工作区和分屏管理、手机标签页导航、待处理收件箱、下一轮消息队列，以及文件与 APK 下载进度和结果反馈。

新增 `mherdr omp`：在新的 Herdr pane 启动 Oh My Pi，或使用完整会话 ID / 路径显式恢复；手机接管沿用该进程。暂不支持热接管已运行的普通 OMP、手机端重启适配器或 OMP 下一轮自动队列。Codex、Pi 和旧会话的身份与输入权边界保持不变。

Android APK 沿用原签名，versionCode 7。此版本仍为 beta：实体手机的中文输入法、键盘、锁屏、系统保存器和厂商后台行为尚需验证；macOS、ARM64 与其他未列出的平台未作为已验收平台。遇到异常请保留草稿并核对原终端，不要自动重发结果不明的消息。
