# 移动端设计与验收

方向：一个随身接回原 Herdr 的开发工具。当前视觉采用用户指定的 Catppuccin / Flexoki 多主题，替代早期整页偏绿的配色。默认 Catppuccin Mocha；阅读字体与字号可调整，技术标识与终端使用等宽字体。以下早期记录保留为历史，当前规范以末尾“多主题与终端浏览”一节为准。

首屏主角是当前 agent 的对话；桌面保留 machine / workspace / pane 侧栏，手机将其收进抽屉。底部只有会话、需要你、开发机三个入口。聊天和终端是同一个 pane 的两种视图。

主动作是向现有 agent 提交任务。消息明确发给当前 machine + session + pane；切换不改变 Herdr 客户端的焦点。正在工作时显示中断操作，等待确认时引导进入原始终端。断网禁用写入，保留编辑，恢复连接后不自动重发。

手机约束：320px 起可使用；输入字体 16px 防止 iOS 聚焦缩放；多行 composer 不占满屏；visualViewport 改变时调整根容器高度，键盘出现时隐藏底部导航；抽屉和连接表单可滚动；下方留安全区。不中断用户向上阅读，只有接近底部时自动跟随新内容。

动效：首次对话内容 180ms 轻淡入；会话抽屉通过 Modal 的滑动转场建立来路；主按钮有 140ms 按压反馈。尊重 reduced-motion；工具应用不增加与操作无关的滚动叙事。

减法：工作区顶部不再重复 logo / 产品介绍；工具输出按组折叠；不把完整文件管理、统计仪表盘和设置页放进聊天。连接说明仅留必需地址和密钥来源。

测试用隔离的 Unix socket fixture 验证移动 UI；独立 Herdr 测试 session 验证真实终端链路。两者不混称为真实 LLM 对话验证。证据与验证结果见 `artifacts/ui/` 和 `docs/verification.md`。

## UI / UX 润色（2026-10-22）

- 对话正文增至 16px，代码 14px；手机顶栏压缩至 60px，兼容模式提示收为单行。对话 / 终端改为分段控件，选中底板移动，触摸目标至少 44px。
- Composer 用整体焦点边框取代 textarea 内框。发送 / 补充按钮显示文字；保存成功后才显示“草稿已保存”，存储失败明确提示并保留输入。离线、等待确认、尚未接管和正在工作各有就近说明。删除原来输入框下重复的“发送到原 pane · 保留完整上下文”，桌面保留快捷键。
- 会话抽屉增加全部 / 需要你筛选、搜索清除、无结果恢复入口及当前 pane 勾选。搜索包含 agent 和 pane ID。搜索、筛选与会话共用滚动区，低高度横屏仍可访问列表；切至桌面立即移除手机抽屉。
- 向上阅读时始终提供“回到最新”，收到新内容时改为“有新消息”，保持当前阅读位置。断开状态明确显示“已断开”及重连按钮。原生空会话删除重复的接管说明和连接技术提示，详情仍在控制权面板中。
- 连接表单先填地址与密钥，再填可选名称；输入保持 16px，窄屏减小容器内边距。开发机列表与使用说明可滚动。没有新增附件、文件工作台或后端协议。

动效仍是短促按压、会话抽屉滑入和 180ms 对话出场，补充分段选中底板 200ms 移动；减少动态效果时直接呈现最终状态。当前操作录屏为 `artifacts/ui/interaction.webm` 与 `artifacts/native-ui/interaction.webm`；三段触发时间在 `artifacts/ui/motion-events.json`，三组精确采样帧在 `artifacts/ui/motion/`：真实 CSS 动画暂停后检查起点、中段和终点，发送另拍按压与完成状态。

完成一轮独立存量润色评审，不打分。评审指出截图部分落在淡入中间帧，已改为等待有限动画结束后取图，并由主 Agent 复看最终截图；采纳原生空态文案减法。连接副标题保留，用于首次连接时说明用途。评审者只检查静态图，动效连续帧与减少动态效果由主 Agent 另验。小号 12px 文案仅用于机器、pane、草稿和连接等次级信息，正文与操作不依赖它；代码横向滚动用于保留命令，不造成整页横向溢出。

基线：`artifacts/ui-before/`；新截图：`artifacts/ui/`、`artifacts/native-ui/`。`phone-detail-2x.png` 为 2 倍像素密度细节图。浏览器视口覆盖不等同于真实手机键盘、IME 或后台行为验收。

## Herdr SSH machines（0.2.2-beta.2）

开发机面板将手动添加的入口与继承的 Herdr SSH 机器放在同一列表，后者标注 `Herdr SSH`、远端 session 和连接状态，认证失败给出电脑侧处理命令，禁用项不可选择。继承条目在 Herdr 中管理，不在手机上删除或改 SSH 密钥。发现机器不会自动切走用户正在使用的目标；刷新会恢复上次选择。

列表读取的是入口 bridge 所在账号的 Herdr profiles，不会同步其他电脑的配置。空列表就地说明这一点；多个入口各自发现其所在环境的机器。草稿与上次 pane 按入口、SSH 目标指纹、session 分开，目标或 session 更换产生新身份，旧选择不可写入新目标。连接尚未准备好时暂停选择 pane，元信息自动重试后恢复指定 session，不先给用户一个可写的本地 pane。

沿用现有按钮、面板和动效，无新增视觉方向。主 Agent 检查 `artifacts/ssh-ui/phone-machines.png`、`phone-remote-chat.png` 和 `phone-remote-keyboard.png`，未见文字重叠或主动作遮挡；没有为本次局部面板改动追加独立视觉评分。浏览器另验 320px、390px、横屏和 450px visualViewport，仍不称为实机测试。

## 多主题与终端浏览（2026-10-22）

用户任务：简洁地读回复、写下一步，并用手势翻阅终端；用户明确指定 Catppuccin + Flexoki 多主题和字体可调。保留原导航与会话身份，集中修正表面、阅读与终端行为，不增加仪表盘或装饰图像。

- 六套本地主题：Catppuccin Mocha / Macchiato / Frappé / Latte、Flexoki Dark / Light；默认 Mocha。共享语义色同时作用于聊天、输入、审批、弹窗、实时终端、ANSI 与历史。正文、次级正文和主操作经过对比度检查。来源与许可见 `theme-credits.md`。
- 顶栏仅加一个“外观”入口。主题使用紧凑列表，字体设置集中在同一面板，主界面不放设置栏。阅读字号 14 / 16 / 18 / 20 px，系统 / 等宽字体；终端字号 11 / 13 / 15 / 17 px。即时预览、刷新恢复，存储失败保留预览并明确显示错误。
- 主体留给对话，发送为主动作；agent 名称、工具组与连接信息使用次级颜色。用户气泡用非对称小圆角。输入焦点、选中标签和按钮使用主题强调色，避免状态栏全部强调。手机连接文案收为“在线”。
- 终端页收起底部全局导航；历史模式隐藏键盘与快捷键，只留刷新和返回。会话切换和机器入口仍可从顶栏打开抽屉。移除旧终端提示“断开连接后 agent 继续运行”的常驻长句，用“实时终端 · 滑动查看历史”说明当前操作。
- 真实 Herdr 的 attach 初始化会开启 alternate screen 和 mouse tracking。备用缓冲区没有普通回滚，触摸 / 滚轮不再直接送入终端：普通缓冲区本地回滚并显示“回到实时”，备用缓冲区读取所选 pane 最近 2000 行只读历史。历史不自动刷新、不抢阅读位置，可滚动选择复制；刷新保留位置。远端能保留多少历史仍由 Herdr 与原程序决定。
- 主题、字号切换不重连 / 清屏。浏览历史不发任何按键，不触碰输入权，草稿仍按机器 / session / pane 保存。输入需点“键盘”或明确点击快捷键。

动效沿用内容 180ms 淡入、分段选中底板 200ms 平移和按钮 140ms 按压；外观面板使用 Modal 淡入。尊重 reduced motion，不加装饰动画。当前证据 `artifacts/appearance-ui/`（主题、20px 阅读、终端回滚 / 历史与交互录屏），原聊天、原生交接、SSH 状态仍分别覆盖在现有 UI 脚本中。手机视口与 Chromium 触控分发不等同于真实手机键盘与后台验收。

独立存量润色评审完成一轮，不打分；未发现静态阻断。已将“长按复制”改为“选择复制”，并补生产 CSS 的入场 / 标签切换 / 按压三组采样帧，详见 `ui-theme-review.md`。外观预览句用于可观察字号效果，保留；主题深浅说明用于选择依据，保留。三轮连续浏览器回归均为90项通过。

## 会话阅读、diff 与内测运维（beta.4）

主任务与六套主题保持不变。阅读工具集中在对话顶部的一行“更早消息 / 上一问 / 查找”，不增加新的底部导航；搜索仅覆盖已加载内容，明确写在输入提示。向前分页保留锚点，查询跳转突出当前消息；切换终端后回到相同阅读位置。原生会话的运行实例与对话、legacy 的精确 transcript 身份都参与分页校验。

Diff 以文件为单位显示路径、增删数量、旧 / 新行号、上下文，文件可折叠，长行横向滚动，超过初始40行逐步展开。统一补丁、apply_patch、工具的旧 / 新文本、Codex文件事件与 Markdown diff围栏共用同一组件。旧 / 新文本片段的行号注明从片段起始计算；缺失内容不从工作目录猜测。六主题的增删文字另做4.5:1对比度校正，终端ANSI原色保持不变。

审批分开呈现目录、命令、原因与文件 diff。尚未收到文件改动时，允许拒绝或交还电脑，暂停“允许本次”，收到对应 item 的 patchUpdated 后即可查看并确认。复制只复制已上报内容，截断明确标识。无额外确认弹窗。终端历史增加搜索、匹配前后跳转、顶部 / 底部，以及选择优先的复制；按钮触摸目标不少于44px。已打开的终端在切回聊天时保留连接和历史。

连接诊断从“开发机”进入，显示客户端 / bridge版本、Herdr和原生状态、SSH汇总。复制报告使用严格字段白名单，不包含地址、路径、标识、密钥或正文；不在手机页面展示启动控制接口。后台管理属于本地CLI，仅管理本工具创建的bridge，不根据PID文件直接终止进程。

本轮继续使用轻按压、对话入场和视图选择底板动效，不新增装饰动效。视觉与交互证据在 `artifacts/experience-ui/`，真实手机键盘 / OS后台行为另列验收。
