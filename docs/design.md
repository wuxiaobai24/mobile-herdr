# 移动端设计与验收

方向：一个随身接回原 Herdr 的开发工具。深石墨色面板、浅绿色状态与主操作、系统中文字体，技术标识使用等宽字体。只做这一条与 Herdr 终端工作流一致的方向，不制作无关的品牌风格候选。

首屏主角是当前 agent 的对话；桌面保留 machine / workspace / pane 侧栏，手机将其收进抽屉。底部只有会话、需要你、开发机三个入口。聊天和终端是同一个 pane 的两种视图。

主动作是向现有 agent 提交任务。消息明确发给当前 machine + session + pane；切换不改变 Herdr 客户端的焦点。正在工作时显示中断操作，等待确认时引导进入原始终端。断网禁用写入，保留编辑，恢复连接后不自动重发。

手机约束：320px 起可使用；输入字体 16px 防止 iOS 聚焦缩放；多行 composer 不占满屏；visualViewport 改变时调整根容器高度，键盘出现时隐藏底部导航；抽屉和连接表单可滚动；下方留安全区。不中断用户向上阅读，只有接近底部时自动跟随新内容。

动效：首次对话内容 180ms 轻淡入；会话抽屉通过 Modal 的滑动转场建立来路；主按钮有 140ms 按压反馈。尊重 reduced-motion；工具应用不增加与操作无关的滚动叙事。

减法：工作区顶部不再重复 logo / 产品介绍；工具输出按组折叠；不把完整文件管理、统计仪表盘和设置页放进聊天。连接说明仅留必需地址和密钥来源。

测试用隔离的 Unix socket fixture 验证移动 UI；独立 Herdr 测试 session 验证真实终端链路。两者不混称为真实 LLM 对话验证。证据与验证结果见 `artifacts/ui/` 和 `docs/verification.md`。

## 原生交接补充

沿用原有方向。控制权条只呈现当前控制端、接管 / 交还操作和电脑接回快捷键。模型和运行实例等详情收进底部面板，避免手机首屏堆叠技术元信息。审批和问题位于会话滚动区，不挤走 composer。小屏横屏和键盘状态都使用紧凑布局。

一次独立存量界面评审未发现静态画面阻断。删除了回答卡中的内部协议方法名、控制条测试模型标识和重复的发送引导。评审建议删除的顶栏 `mobile-herdr` 实际是当前工作区名称，保留它以明确发送目标。按钮按压、详情面板滑入和对话出场沿用现有反馈；评审只观察视频抽帧中的状态变化，没有宣称完成细粒度动效或真实手机验收。

当前证据：`artifacts/native-ui/phone-desktop-owner.png`、`phone-approval.png`、`phone-keyboard.png`、`phone-returned.png` 和 `video/`。键盘截图的可见高度为 450px，图片剩余黑区不属于可交互视口。
